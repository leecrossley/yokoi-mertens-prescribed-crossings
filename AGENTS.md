# Contributing to this result

Ongoing work on this result belongs in [`leecrossley/quadratic-mertens-first-crossings`](https://github.com/leecrossley/quadratic-mertens-first-crossings/tree/main/results/yokoi-mertens-prescribed-crossings). Edit its `results/yokoi-mertens-prescribed-crossings/` directory in a branch of that repository and open the pull request there. For a distinct note on the same mathematical question, add a result directory and an entry in the [family index](https://github.com/leecrossley/quadratic-mertens-first-crossings/blob/main/RESULTS.md).

Use the [research contribution guide](https://github.com/leecrossley/quadratic-mertens-first-crossings/blob/main/AGENTS.md) to choose a different family when the mathematical scope calls for it. Keep the [original releases](https://github.com/leecrossley/yokoi-mertens-prescribed-crossings/releases), citation identifiers and verification records available.
